# Advent of Code 2025

My solutions and experiments for Advent of Code 2025.

## Tech stack

- Python
- C++
- Algorithmic problem solving
- File-based puzzle inputs

## Progress

The repository currently contains work for Days 1–7, generally split into Part 1 and Part 2 solutions. Some days use C++ and others use Python as I practice choosing an appropriate approach for each puzzle.

## Run a solution

Python example:

```bash
python "day 2/part 1.py"
```

C++ example:

```bash
g++ -std=c++17 "day 1/part 1.cpp" -o day1-part1
./day1-part1
```

Run commands from the repository root so relative input paths resolve as expected.
